# Inditex Radar

Inditex markaları (Zara, Bershka, Pull&Bear, Stradivarius, Massimo Dutti, Oysho) için sipariş öngörü ve numune planlama uygulaması. Mobil öncelikli PWA (React + TypeScript + Vite).

```bash
npm install
npm run dev        # geliştirme
npm run build && npm run preview   # üretim
```

Telefonda: yayınlanan adresi açıp "Ana ekrana ekle". Araştırma ve yol haritası: [docs/YOL_HARITASI.md](docs/YOL_HARITASI.md).

> Mevcut veriler **örnek (demo)** veridir. Gerçek veriyi Daha → Ayarlar → "Veri içe aktar" ile CSV/JSON olarak yükleyin.
